# PHONE_SETUP_V4

1. Upload this package to your repository.
2. Open Actions → uncommonAI Autopilot V4.
3. Run `research` once manually.
4. Open the issue it creates.
5. Comment `APPROVE`.
6. Wait for the production artifact.
7. Review the artifact.
8. Comment `PUBLISH`.

Do NOT add API keys to source files.

For production, add OPENAI_API_KEY under:
Settings → Secrets and variables → Actions.

YouTube publishing is deliberately disabled until the OAuth refresh token is
configured. This will be handled as the next setup step.
